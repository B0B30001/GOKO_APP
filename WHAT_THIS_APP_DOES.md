## 🎯 **How to Use Your App (Right Now)**

### Start Playing Immediately:
1. **Tap "Start Playing"** on login screen (skip OGS)
2. **Choose "Play"** button on home screen
3. **Select "vs Friend"** (same device)
4. **Pick board size**: 9×9, 13×13, or 19×19
5. **Play!** Black moves first

### Learn with Puzzles:
1. Go to **"Learn"** tab (bottom navigation)
2. Pick a topic: **Captures**, **Liberties**, **Life & Death**, or **Ko**
3. Tap **"Start First Puzzle"**
4. Place stones to solve the puzzle
5. Use **"Hint"** if stuck
6. See explanation when you win!

### Game Features:
- **Undo** button - take back moves
- **Pass** button - skip your turn (two passes = game over)
- **Redo** button - redo undone moves
- **Refresh** button - start new game
- **Settings** - toggle coordinates, change theme
