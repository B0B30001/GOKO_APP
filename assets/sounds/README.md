# assets/sounds/

Place your MP3 sound files here. Required filenames:

| File                 | When it plays                          |
|----------------------|----------------------------------------|
| stone_place.mp3      | Each successful stone placement        |
| capture.mp3          | When stones are captured               |
| correct.mp3          | Correct puzzle move (rising ding)      |
| wrong.mp3            | Wrong puzzle move (low buzz)           |
| complete.mp3         | Puzzle/drill solved                    |
| lesson_complete.mp3  | Tutorial/lesson finished               |

Free sources: freesound.org, zapsplat.com, pixabay.com/music
